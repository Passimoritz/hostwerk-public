# Dateifreigabe

[← Zurück zur Übersicht](README.md)

Einen Ordner per SFTP oder als Download-Link freigeben – für Welten, Mods oder Fotos.

![Dateifreigabe](img/ext-file-share.jpg)

### Gut zu wissen

- Fingerabdruck Beim ersten Verbinden zeigt das SFTP-Programm diesen Fingerabdruck. Stimmt er überein, geht die Verbindung wirklich zu diesem PC.
- Router Windows fragt eventuell einmal, ob Hostwerk Verbindungen annehmen darf – für private Netzwerke erlauben.
