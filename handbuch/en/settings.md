### Good to know

- Themes from extensions A theme changes colours, font, rounding and spacing – only through checked values. Hostwerk only applies it if texts and controls stay easy to read (WCAG 2.2 AA). If the extension is removed, Hostwerk’s own look returns.
- Accent color Color for buttons, marks and highlights – you see it everywhere right away. Extensions adopt it. With custom colors Hostwerk adjusts buttons and text so everything stays readable.
- Interface zoom Makes text and controls larger or smaller everywhere – up to 200 % without cutting anything off. Applies wherever you open Hostwerk – in the browser and on your phone too.
- Your name Stays in the settings on this computer – not in setup files, exports or logs; error reports replace it with “<name>”. It is only used where you turn it on below.

### Updates

![Updates](img/settings--updates.jpg)

> “Stable” only gets finished versions, and new versions arrive step by step – first for a few, then for everyone. “Preview” also gets test versions right away as soon as they appear. You can switch back to “Stable” at any time; an installed test version stays until a newer stable one arrives.
> Small updates within the same version (e.g. PHP 8.4.11 → 8.4.12). Hostwerk downloads the new version next to the old one, switches over and quickly checks that everything runs. If it doesn’t, the old version stays active. Hostwerk never makes big version jumps on its own.

### Advanced

![Advanced](img/settings--advanced.jpg)

> Cache Hostwerk reloads everything here when needed. Projects, databases, backups and settings stay untouched.
> Maintenance Maintenance runs as its own window and loads no extension – so none can interfere. There you turn extensions off, roll them back or remove them, and update, repair or remove Hostwerk. If Hostwerk no longer starts: Start menu → “Hostwerk – Maintenance” or press F8 while it starts.
